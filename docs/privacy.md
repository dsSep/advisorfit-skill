# 隐私说明

## 下载的Skill

AdvisorFit是一组工作说明，不提供独立的简历上传、账户或云端档案服务。在ChatGPT／Codex／WorkBuddy中使用时，文本、附件、搜索和其他工具的数据处理取决于对应平台、账户设置及工具。Skill不能承诺平台不保存聊天。

建议使用脱敏简历：删除电话、邮箱、学号、证件号码、家庭住址和无关个人资料，保留分析所需的专业、经历、申请阶段和约束。

## 在线体验

网站只提供固定虚构案例，没有简历上传入口。修改后的问题、固定背景、证据和Skill说明会发送给DeepSeek生成回答。请勿粘贴真实简历、联系方式或其他敏感内容。

应用数据库不保存提问正文或回答全文，仅保存额度与必要运行状态：站点用户标识的摘要、请求编号、日期、占额及忙碌时间、返回的token用量、保守估算预占金额。摘要仍可用于关联本站额度，不等于完全匿名。记录在后续有效请求时清理七天前数据，没有新请求时可能保留更久。

结果可在页面下载。ChatGPT登录、托管和模型服务商可能依各自政策处理数据；应用不存正文不等于第三方未收到正文。密钥仅保存在服务端，不包含在下载包、网页代码或案例材料中。

WorkBuddy真实案例中观察到宿主把个人摘要写入本地记忆文件。WorkBuddy适配说明要求不主动将真实简历和联系方式写入长期记忆，但这不能关闭宿主记录或替代客户端隐私设置。分享任务前请检查附件、输出和分享权限，优先使用脱敏副本。
