# 公开案例的匿名处理

公开测试材料使用院校、专业和导师代号。同姓导师用更长的首字母区分，例如W.p、W.h、L.w、L.q。它们是原案例身份的替代标记，不是新导师或新实验。

原提示、报告、邮件、对照片段中的身份字段和可反查身份的来源入口已处理，平台原始标记和引用导出留在私有档案。公开校验值只对应匿名副本，不能当成未改动原始输出的校验值。具体判断、错误与限制保留，不借匿名处理提高评价。

匿名案例便于理解表达差异；真实导师的归属和原网页核查需要原始私有档案，公开副本不再提供完整身份核验能力。方法、题目和经历组合仍可能关联身份，不承诺无法重新识别。请勿在公开Issue提供真实简历、聊天链接或密钥。

[导师选择静态名单](whu-data-science-advisor-selections.md)是单独的公开信息目录，不属于测试简历；其教师姓名和官方主页按该页用途保留。
