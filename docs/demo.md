# Sites 演示范围

三个入口分别是找候选、分析指定导师、比较导师。选择固定虚构案例，查看背景与证据，修改简短问题，再通过 API 实际执行 AdvisorFit 方法。没有普通模式切换；不实时联网，不连接 MCP，不使用预写答案冒充生成，不把演示当作条件对照实验。

服务端从 lib/skill-data.json 读取完整核心与当前任务需要的原版研究、准备或邮件参考。该文件由 python scripts/package_skill.py 从发布源生成，含版本与逐文件哈希；构建前运行 python scripts/check_release.py 检查同步。完整包保留五份参考；无 MCP 时不加载其契约，案例不涉及检索评测时不加载检索评测参考。页面列出实际加载文件。

当前模型为 deepseek-flash，[官方说明](https://api-docs.deepseek.com/)称其对应 V4.1-Flash-1017。非思考模式（thinking disabled / reasoning_effort none）、最大4096 token，超时120秒；不展示内部推理。实际响应型号与用量以返回为准，没有用量则不推算费用。原计划 GLM-5.3 在2026-11-05返回429/1113（余额不足），用户授权切换；此失败不是 Skill 质量结论。

## 访问与数据

站点配置为公开，ChatGPT登录后才可生成。当前匿名HTTP访问仍被Sites登录页拦截，免登录浏览尚未通过；不绕过平台身份保护。服务端检查身份与本站Origin；北京时间每日每人5次、全站100次，原子预占阻止并发越额、同用户并行与重复请求。输入最多2000字。请求发给模型即计一次，失败不自动重试；输入及配置校验失败不扣次数。

DEEPSEEK_API_KEY 仅存Sites服务端机密配置。数据表只存随机请求编号、站点用户ID的SHA256摘要、日期、占额时间、忙碌期限及token用量；不存邮箱、问题、生成全文或密钥。7天前记录在下一次有效生成预占时删除（惰性清理，并非定时清理）；没有新请求时可能保留更久。摘要仍用于额度识别，不宣称完全不可关联。结果留在访客页面，可自行下载。

提交前提示内容会发送给DeepSeek，建议仅用虚构或脱敏资料。访客无需密钥、不向访客收费；模型费用由维护者承担。匹配不代表招生，邮件由用户审阅发送。

## 验收边界

本地自动检查不代替部署验证。真实生成、登录、网关身份头保护、D1额度及手机/键盘操作分别记录，未通过项保留为未验证。独立站点不是ChatGPT原生插件，不自动更新账户插件或旧MCP。
