# 小红／N.l：0.2.5网页回答的具体差异

这是开发者已知条件的定性对照，不是盲评，不计算总分。两份收到的主回答已完整保存；没有补写被测内容。分析日期：2026-11-05。

## 先看实验边界

用户确认：同一份虚构简历、同一句简短请求、免费账号、相同默认模型及思考强度；增强组使用0.2.5。**但分享页的实际字段存在差异：无Skill为 `model_slug=gpt-6`，有Skill为 `model_slug=gpt-6-t-mini`；两份 `default_model_slug=auto`。**字段不相同，因此不能确认后台实际模型相同，也不能把所有差异归因于Skill。不根据内部名字猜测性能高低或思考强度。

实际Skill加载文件、搜索权限、账户记忆影响和完整工具输入输出未恢复。提示及简历由用户在本轮提供、确认相同，未从被测原聊天独立恢复。两份分享记录都是完成状态，但不是完整会话导出。完整性和最小字段证据见[记录](record.json)。删除前一聊天不等于关闭账户记忆。

## 这份回答具体好在哪里

### 1. 把未知技能留为未知，减少无依据的负面判断

无Skill原句：“没有自然语言处理、知识图谱的实践经验”。简历实际写的是这些实践经验“未提供”，不能推出没有。

Skill原句：“这里要特别说明：NLP、知识图谱和模型训练的实践经验是未提供，而不是已经证实你完全不会。”表格也写“未提供实践经历”。

**用户收益：**不会仅因简历没写某技能，就被当作已经确定的短板；后续应补问或保留未知。这是本例最清楚、可逐字核对的改善。

**保留缺陷：**开头仍写“你不是已经具备成熟数字人文、自然语言处理或知识图谱研究能力的学生”。虽然没有宣称完全不会，仍超过现有材料能证明的范围。不能宣传已彻底解决未知能力误判。

### 2. 从建议阅读，推进到逐篇解释研究及其与经历的联系

无Skill主要在计划中列两篇题目，并建议：“每篇论文整理研究问题、研究方法、主要结论三个部分。”没有逐篇提供年份、作者、研究分析及详情入口。

Skill对地方志论文解释：“地方文化报道与地方志虽然不是同一种材料，但都涉及历史文化信息的提取和组织。”并提醒：“第一作者为黎安润泽，不能将整篇论文的具体工作全部归于N.l老师。”同时提供论文详情引用。

**用户收益：**知道先读哪篇、为何与自己的18篇报道索引有关；能够打开具体论文页，而不是自己从题目重新找起。该论文作者、作者贡献与摘要已在[期刊页面](https://www.libraryjournal.com.cn/CN/abstract/abstract2834.shtml)核对。评价依据是解释内容和可追溯入口，不是四篇比两篇多。

**保留缺陷：**名人知识库论文当前只取得学院搜索索引，正文访问超时；不能将全部论文标成已核验。2025年论文DOI正文拼错，末尾更正为正确DOI，但错误仍留在原位置。没有核查全部全文。

### 3. 缩小起步规模，并增加逐项检查

无Skill：“我给你安排一个30天的准备计划。”第二周完善18篇报道，后续学习关系组织、写研究设想。它本来就不要求训练大模型，也已建议先把现有18篇整理可靠。

Skill：“第一阶段：只使用5篇报道”；“按每天30分钟安排，先做两周”。给出字段表及检查：“人物和事件是否有原文依据？”“是否有重复记录？”

**用户收益：**第一次交付范围更小，知道做完要检查什么。按每天30分钟计算，计划分别约15小时与7小时；这是建议安排的算术换算，不是实测节省8小时，更不能宣称效率提高一倍。

**保留缺陷：**5篇／两周仍是项目预览，没有真正压到一条材料的当天操作；没有明确本轮请用户提供哪条原文、助手示范哪些字段、用户如何验收示范。结尾仍是“我可以继续帮你完成第一条材料的标注示范”。没有后续辅导记录，不能宣传已经带做完成。

### 4. 明确哪些论文只需理解，避免把前沿技术直接变成入门任务

Skill谈2025年档案开放审核论文：“现阶段以理解研究问题为主，不建议直接把它作为你的第一个实践项目。”它把导师研究延伸与申请者当前可承担的工作分开。

**用户收益：**看到导师做大模型，不必马上把训练模型当作联系前的门槛。但普通组也已说“不建议你现在投入大量时间学习深度学习或训练大模型”，所以这是增强组更具体的论文层面解释，不能说普通组没有考虑资源限制。

## 哪些方面没有证明更好

- **个性化并非Skill独有。**无Skill已有“你是项目参与者，负责部分数据规范和质量核查工作，而不是独立建设了一个数字档案系统”，也联系62条目录、18篇报道、每天30分钟等具体条件。不能宣传普通组只会泛泛介绍导师。
- **匹配结论仍前后不一致。**Skill开头“目前还不能认定为高度匹配”，后文又“初步匹配：较高，值得进一步争取”，表格多处“高匹配”。无Skill把“尚未确定长期研究主题”评为“长期研究兴趣匹配｜很高”也偏强。两者都需把已有兴趣和长期承诺分开。
- **两份都没交付完整邮件。**本次用户只问“适不适合我”，并未明确要求当轮写邮件，所以不按未遵守用户指令处理；但不能用本例宣称已经验证“简历→匹配→项目→完整邮件”的产品闭环。Skill应在自然下一步确认用户是否需要邮件，并按真实阶段写。
- **篇幅没有缩短。**原始纯文本分别7,797与7,957字符（含平台标记），不代表阅读时间或token量。Skill的价值体现在某些内容更可用，不能宣传更短或更快。
- **招生和指导条件：两组都谨慎。**普通组已经区分公开培养经历与2027级实际进组安排；增强组延续这一点，没有证据表明这是新增优势。

## 建议下一轮只验证三个动作

1. 给同一组固定背景，检查未知能力在开头、表格、结论和邮件是否一致，不只检查最后一句免责声明。
2. 统一追问“现在带我完成最小第一步”，提供同一条公开材料，检查是否实际完成一条示范并给可核对依据。
3. 明确要求申请硕士指导／进组邮件，检查未完成项目没有被写成经历。

下一轮先保存界面设置和可取得的实际模型字段；若后台仍不同，按默认账户真实使用案例记录，不冒充严格单变量实验。优先复用同一提示、同一材料，多次独立运行后再讨论重复稳定性。这轮不自动启动新实验，也不据此直接修改或发布新版本。
