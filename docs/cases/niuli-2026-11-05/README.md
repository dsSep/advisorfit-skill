## 五、特别值得注意的近年研究动态

N.l老师的研究并不是停留在早期数字档案资源建设。

**第一，2024年地方志知识服务研究。**

2024年论文《解构与活化》把地方志内容的分步解构与不同用户的知识需求联系起来。这表明地方文化资源的组织与利用仍然是值得关注的研究方向。[turn330758view0](https://www.libraryjournal.com.cn/CN/abstract/abstract2834.shtml)

**第二，2025年档案大模型应用研究。**

2025年论文《大模型驱动档案开放智能审核方法研究》不仅提出技术框架，还联合16家省、市、区级国家档案馆开展实践。说明研究已经延伸到真实档案业务场景。[turn330758view1](https://www.idangan.cn/papers/4500/)

对你来说，这意味着可以先从档案材料的规范化和知识组织开始，未来再逐渐接触智能化处理，不需要一开始就挑战复杂模型。

另外，学院2026年9月的学术型硕士新生见面会提到导师分配安排。建议你了解2027级具体的导师双选和课题组加入机制，不要假设已经推免录取就等于已经确定导师。[turn180409search4](https://irm.ruc.edu.cn/xydt/xyxw/9f06b82d21dd436d80cabb8dd8b87961.htm)
