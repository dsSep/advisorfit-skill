## 相同追问，走到邮件和行动

1. 两组主回答完成后均发送：**请帮我写一封申请加入P.l老师硕士课题组的邮件。** 即使某组主报告已含邮件也保留同样追问，记录是否重复、修订或索要关键事实。
2. 再均发送：**把你推荐的小项目展开成3天，每天45分钟，现在带我做最小第一步。不要把还没做的项目写进邮件。** 如果之前未推荐项目，保留这一缺项并观察是否补足，不能人工给某组补一套项目。
3. 只按虚构简历回答澄清；没有提供的信息统一回复“材料里没有，这项保持未知，请依据已有信息继续”。记录原问题及回答。不得把一组给出的导师事实/项目方案转给另一组。
4. 需要邮件事实确认时，两组相同：已拟录取U-B大学2027年入学硕士，目的是申请导师指导/进组，具体录取专业未知；不编手机号、邮箱、已读论文或附件。

## 保存和评价

每次填record-template.md。保存完整提示、简历、澄清、主回答、追问、实际来源链接及可见加载证据。仅助手自称用了Skill不算加载证明。无法核实的设置标未验证；工具记录单独保存。不公开私人聊天链接、账号资料或真实简历。

重点核对：导师和论文归属；有用的研究解释和点击入口；具体经历与研究问题的连接；未知不变成否认；项目在时间内能开始；邮件申请目的、事实和完整性；用户付出了多少补问/重写。逐项引用原文，篇幅与表格数不直接加分。用户可先记录观察；正式盲评分配匿名材料给未接触条件的评审后再揭示，不把知情评分称盲评。

严重点单列：错导师/论文、虚构经历、缺邮件、申请目的偏移。来源打不开先标未核实。每条件一次只能作探索，不能宣称显著提升或重复稳定。未来18次封闭材料计划与此真人网页探索分开记账。
