# 评测材料与待办

[完整固定案例](../skills/advisorfit/evals/cases.json)包含三类封闭材料练习：完整真实邮件、现在开始第一步、只比较不越界。输入与逐项要求保留原样，虚构材料不代表现实导师。

计划18次模型测试：三类案例 × 普通/AdvisorFit两条件 × 每条件三次。**状态：计划，未运行。** 不补写模型答案或评分，不产生未授权费用。固定模型、参数、完整任务提示与材料，采用独立会话和相同搜索权限；普通组不加载说明，增强组记录实际版本及文件哈希。另行明确普通助手也获得完整提示，不能用简略提示夸大差距。

每次保存完整输入输出、时间、澄清、追问与失败。错认导师、错归论文、虚构经历、遗漏邮件、目的偏移单列，不被总分抵消。独立评审先看匿名完整输出，后揭示条件；原文缺失不正式评分。

这些测试不衡量实时网页搜索、自动触发或MCP增量价值。真实发现候选、指定导师和多导师比较需另行核验。[旧证据](../docs/evidence.md)不计入待办已完成结果。
