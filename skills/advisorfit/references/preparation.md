# 从研究交集到可执行小项目


先用白话连接“你已有的基础→导师具体问题→这周能掌握的一小步”。解释用户没接触过的概念，不能默认会BERT、RAG或学术评价。只选一个小问题，不要求一周精通新领域或复现整篇论文。

先设计一个可快速体验导师问题的小项目，用短段落展示：**项目是什么 → 为什么接得上你的哪项技能 → 为什么体现这位导师的具体研究 → 材料→操作→可见产物的流程 → 预计总时间与费用/工具 → 前10–20分钟怎么开始**。最小版本优先1–3条材料/一个对象，先得到一个可检查的产物；不要从5家公司、几十篇论文或完整系统起步。程序员可复用已有代码，财经分析者可用熟悉的公告与信息核验方法，其他用户用自己真实背景连接相应研究；这只是设计方法，不让所有导师都做财经/检索项目。

阅读服务于项目里一个明确问题。宿主先打开资料并给白话讲解、示范一小段和核对办法，用户可点击论文入口核对，不要求其先自行啃完论文再动手。提供一段可以直接发给当前ChatGPT的项目请求，让AI协助提取、解释或搭出第一版，用户负责检查依据和记录观察。保留至少一个需要用户理解/判断的动作，不把AI代写结果当用户掌握。引用论文/教程时附真实链接与对应位置，无法访问时缩小任务而不编资源。

完整报告的邮件之后，邀请用户选择：“要不要现在先做这个项目的最小版本？也可以按1天、3天、7天、两周或一个月展开，并调整每天时间。”期限只是项目安排方式，不是独立课程清单。一个月约定为30或31天；缩短时保留一个最小产物，延长时扩展材料、对照或检查深度，不只改日期。选择后先带用户完成最小第一步，再继续；用户已给时间时直接使用，不重复问。

用户要求展开或选定期限后，先重复一句“我们要做出的产物是什么”，再按项目阶段安排时间。第一步写用户现在能点击/粘贴/修改什么、AI接下来会帮什么、用户怎样检查；附可直接发送的请求和一个输入→预期产物教学例子，避免泛泛“学概念、读论文、做实验”。陌生词随操作解释，一次只引入当前动作需要的概念。每天/每阶段给验收、卡住时的简化动作和真实资源位置。默认复用当前聊天、已有资料和工具，不要求额外API密钥、付费模型、数据集下载或安装框架。用户提交产物后先反馈，再进入下一步；全部结果可能不改善，必须如实记录。教学例子不是导师成果，也不证明新方法有效。

MCP详细辅导写入PlanAction.guidance：why、concepts、steps、example、if_stuck、resources（title/url/start_here/evidence_ids），assistant_support给可直接发给AI的求助。小项目预览写入AlignmentPlan.project_brief：title、research_question、starting_advantage、why_this_advisor、student_fact_ids、professor_evidence_ids、workflow、first_step、assistant_prompt、deliverable、estimated_minutes、money_policy、upgrade_condition。两侧依据分别指用户已确认的已有能力与当前导师有效研究来源；仅身份材料不能证明项目对口。project_gaps非空表示还缺个性化项目，teaching_gaps非空表示还缺逐步帮助；host_refined标签不代表已满足质量。展示预览前补项目，详细辅导前补教学。默认7天每天1小时，期限支持1–31天，多导师共用总时间；计划可跳过。

**完成项目后可升级邮件**：明确说“实际完成并核对后，可以把你做了什么、得到哪些可展示产物、观察到什么及局限写进邮件，让能力表达更具体”。给一条待完成后填真实信息的升级位置说明，和当前完整邮件分开。项目完成、本人角色及阅读状态须重新确认后才改入正文；AI生成代码/笔记不自动证明用户已理解或完成。它可能增强可讨论的依据，不能保证导师更欣赏、接收或提高录取概率。

例如学习检索评价，先解释“相关性=结果是否解决查询问题”，再指导写一个具体问题、保存前五条结果、用“回答/部分回答/无关”标注并给理由。演示一条标注后，让用户自己完成其余；看不懂论文先读摘要的问题和结论，各写一句疑问。示例只在导师方向适用时使用，不让所有学科都做检索实验。


## 已给材料时，直接开始

先交最小版本，再说明如何扩展。例如用户只有“正在整理40份政策文件”的经历、尚未给文件内容：只请其提供1份文件的官方链接或相关原文，助手协助做1行“标题/发布机构/日期/依据”记录，用户逐格回看原文；此时不能声称已经核对40份。其他领域同样从一个对象和一件可检查产物开始，不统一套政策表格。

用户已选择期限、时间和材料时直接沿用，不重新要求选择方案或重述简历。先给全程简短安排，再在当前回复完成最小第一步的示范：从提供的材料里处理一条、列出原文依据和判断理由，请用户只检查或完成紧接着的一小步。没有材料时只索取最小必需输入，不把搜集几十份资料当起点。材料在上一轮已经提供时不再次索取。

首步必须让用户知道：我现在提供/修改什么；AI已经示范/接下来帮助什么；我用什么标准核对。用已有原文做示范时注明它是教学结果，不是用户已完成的研究；纯虚构示例显式标注。总时间包括找资料、阅读、安装、标注和检查，不把这些隐藏到预算外。完成项目后再核对事实并升级邮件，不推定效果一定提升。
