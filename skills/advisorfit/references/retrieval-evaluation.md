# 检索练习的比较与标注

仅在项目确实涉及检索评测时读取。

调查研究、数学或其他方向按相应方法设计，不要求先做检索实验。检索评测明确语料规模、查询数与相关性标注范围。比较原查询与改写/扩展查询时，先运行两种条件，合并Top-k结果并按文档编号去重，再按同一规则标注所有待评结果；只标原查询结果不能评价改写结果，未标注不得直接算不相关。计算Precision@k前先核对每条查询、每种条件的前k个位置：相关性未知时，优先补读并完成标注；时间不足则缩小查询数或k并对所有条件使用相同范围。仍有未知时只报告区间：已确认相关数r、未知数u，Precision@k下界r/k、上界(r+u)/k；不能只删除未知并换分母，也不把区间当成单一分数。不同条件区间重叠时不据此断言谁更好。检索不足k条时明确缺失位置按零计、分母仍为k；重复文档在单个排名中仅算首次出现。原始排名和标注保留，零结果也如实记录。优先少量查询（如5条、每种Top-5最多50条去重前记录），以实际标注时间缩小任务。Recall需要已知全部相关文档的分母，只标Top-k时改用Precision@k和错误分析。手工扩展替代模型后不能称为LLM实验。
