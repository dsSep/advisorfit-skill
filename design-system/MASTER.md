# AdvisorFit 演示页设计规范

本页沿用项目已批准的「墨色 / 暖纸」品牌；不是自动检索模板。此前 newsletter / portfolio 检索与产品不匹配，不作为设计依据。补充查询 `form loading feedback --domain ux` 返回表单提交反馈与加载状态指南，适用于本页。

- 底色 #f5f2eb；表面 #fffcf7；墨色 #1d2028；边线 #dedbd3。
- 强调 #7569af；可读强调文字 #605483；浅紫 #eeeaf5。金色 #b48a52 仅用于装饰序号。
- 正文 #292b31；次要正文 #52545b；图注 #777975；错误 #a8543f。
- 标题 Georgia / 中文宋体；正文系统无衬线，根字号 16px。微标签只承担英文栏目辅助，不承载重要提示。
- 卡片 1px 边框、4px 圆角、无阴影。桌面双栏：左侧案例与提问，右侧生成结果；800px 以下单栏。
- 桌面内容最大宽 1280px；页边距 48px，移动端 20px。正文输入 14px；生成正文 14px，1.95 行高。
- 主按钮墨色，不使用紫色渐变；所有操作按钮至少 44px 高。键盘聚焦保留明显轮廓。
- 只在真实请求状态显示「正在连接 / 正在生成」，不模拟检索、不显示虚构进度条或评分。
- 固定案例全部明确为虚构。用户提问最大 2000 字，背景与证据只读；发送前明确同意将材料交给DeepSeek。
- 输出用 React 文本节点安全呈现；允许下载本地 Markdown；无真实用户姓名或邮箱显示。
- 尊重 reduced-motion，默认只使用非关键的轻量加载旋转。
